# Две версии игры и как их собирать

Проект один, код игры общий. Версию определяет **активная платформа сборки** в Unity.

| Версия | Платформа | Реклама | Где публиковать |
|---|---|---|---|
| Яндекс Игры | WebGL | PluginYourGames 2 (YG2) | [Яндекс Игры](https://yandex.ru/games) |
| Android-приложение | Android | Yandex Mobile Ads (РСЯ) 8.5.0 | RuStore (APK), Google Play (AAB) |

Меню сборки: **Tools → Crossword → Android**

| Пункт | Что делает |
|---|---|
| Build APK (test) | APK для проверки на устройстве. Разрешает демо-блоки рекламы |
| Build APK (release) | APK для RuStore. Требует своих блоков РСЯ и keystore |
| Build AAB (release) | AAB для Google Play. Те же требования |
| Apply Player Settings | Применяет настройки Android, gradle-шаблоны и иконку, без сборки |
| Resolve Dependencies | Резолв Android-зависимостей (EDM4U) |
| Create Mobile Ads Config | Создаёт `Assets/Resources/MobileAdsConfig.asset`, если его нет |
| Set JAVA_HOME For Editor | Подставляет JDK из состава Unity, если резолв зависимостей жалуется на JAVA_HOME |
| Fix Scripting Defines (в Tools → Crossword) | Чинит Android-дефайны, если их сбил плагин YG2 |

Меню сборки версии для Яндекс Игр: **Tools → Crossword → WebGL**

| Пункт | Что делает |
|---|---|
| Build (release) | Собирает WebGL-версию в `Builds/WebGL/crossword-<версия>`; если активна другая платформа, сначала переключает на WebGL и продолжает сам |
| Apply Player Settings | Применяет настройки WebGL (шаблон Яндекса, Brotli, без потоков), без сборки |
| Switch Platform To WebGL | Просто переключает активную платформу обратно на WebGL после Android-сборки |

После сборки PluginYG2 сам упаковывает билд в архив рядом с папкой:
`Builds/WebGL/crossword-<версия>_YandexGames_Build(N).zip` — именно этот файл загружается в консоли
разработчика Яндекс Игр (внутри `index.html` лежит в корне архива, как требует площадка).

## Как устроено разделение рекламы

```
Игровая логика (CrosswordManager)
        │  ShowRewarded / TryShowInterstitial
        ▼
   AdsManager          общие правила: один показ за раз, интервалы,
        │              ровно один вызов колбэка, таймаут открытия, пауза звука
        │  IAdsBackend
        ▼
   PlatformBridge      единственное место с #if по платформе
        ├─ не Android → YandexGamesAdsBackend   (PluginYG2)
        └─ Android    → YandexMobileAdsBackend  (Yandex Mobile Ads)
```

Игровой код не знает, какая платформа активна: он вызывает `AdsManager` и получает результат
`Rewarded` / `NotWatched` / `Unavailable`. Подсказка в игре выдаётся только при `Rewarded`.

Правила показа (одинаковые на обеих платформах):

- межстраничная не показывается в первые 60 секунд после запуска и чаще одного раза в 90 секунд;
- после ролика за награду межстраничная откладывается;
- одновременно показывается только одна реклама;
- если реклама не открылась за 4 секунды, показ считается несостоявшимся;
- награда принимается в течение 0,3 секунды после закрытия рекламы (SDK иногда сообщает о ней позже).

### Зачем нужен маркер-дефайн

PluginYG2 добавляет символ `YandexGamesPlatform_yg` во **все** платформы, включая Android. Под этим
символом компилируется мост к JavaScript (`.jslib`), которого на Android нет — приложение падает при
старте с `EntryPointNotFoundException: IsInitSDK_js`.

Плагин проверяет наличие своего символа по подстроке, поэтому в Android-дефайнах символ заменён на
маркер **`ANDROID_APP_WITHOUT_YandexGamesPlatform_yg`**: подстрока находится, плагин символ обратно не
добавляет, бесконечной перекомпиляции нет. Следит за этим `Assets/Scripts/Editor/AndroidDefinesFixer.cs`:
он чинит дефайны при загрузке редактора, вручную (Tools → Crossword → Fix Scripting Defines) и перед
сборкой. Если дефайн всё же успел вернуться, сборка прервётся с просьбой запустить её заново —
скриптам нужно перекомпилироваться.

**Дефайны WebGL трогать нельзя** — там `YandexGamesPlatform_yg` обязателен.

## ID рекламных блоков РСЯ: где взять и куда вписать

### 1. Получить ID

1. Войдите в [партнёрский интерфейс РСЯ](https://partner.yandex.ru) под своим аккаунтом.
2. Добавьте новое приложение: **Площадки → Добавить площадку → Мобильное приложение**.
3. Платформа — **Android**, идентификатор приложения (package name) — **`com.tupuppo.crossword`**.
   Он должен совпадать с пакетом в сборке, иначе блоки не будут отдавать рекламу.
4. Создайте в этом приложении два рекламных блока:
   - **Межстраничный** (Interstitial) — показывается между уровнями;
   - **С вознаграждением** (Rewarded) — открывает букву-подсказку.
5. Скопируйте ID блоков. Формат: `R-M-XXXXXXX-1`.

### 2. Вписать ID в проект

Файл: **`Assets/Resources/MobileAdsConfig.asset`** (в Unity: папка `Assets/Resources`, ассет
`MobileAdsConfig`). Поля в инспекторе:

| Поле | Что вписать |
|---|---|
| Use Demo Ad Units | **Снять галку** — иначе будут использоваться демо-блоки Яндекса |
| Interstitial Ad Unit Id | ID межстраничного блока, например `R-M-1234567-1` |
| Rewarded Ad Unit Id | ID блока с вознаграждением, например `R-M-1234567-2` |
| Interstitial Interval | Минимальный интервал между межстраничными, секунды (по умолчанию 60) |

Пока галка `Use Demo Ad Units` стоит или поле пустое, используются демо-блоки
`demo-interstitial-yandex` и `demo-rewarded-yandex`: реклама показывается всегда, но денег не приносит.
Релизная сборка с демо-блоками не запустится — сборщик остановится с ошибкой.

### 3. Проверить, что реклама работает

Подключите телефон и смотрите Logcat (`adb logcat -s Unity:V YandexMobileAds:V`):

- `Yandex Mobile Ads <версия> integrated successfully` — SDK подхватился;
- `[Ads] backend: Yandex Mobile Ads (own units)` — используются ваши блоки;
- `[Ads] interstitial loaded`, `[Ads] rewarded loaded` — блоки отдают рекламу;
- `[Ads] rewarded result: Rewarded` — награда выдана.

В редакторе Unity рекламы нет: SDK подменён заглушкой, показ имитируется за 1 секунду.
Это нормально, проверять рекламу нужно на устройстве.

## Как собрать релиз

### Один раз: keystore

1. **Player Settings → Publishing Settings → Custom Keystore** → создайте keystore и ключ,
   задайте пароли. Храните файл и пароли отдельно: без них выпустить обновление невозможно.
2. Unity **не хранит пароли keystore на диске** — после перезапуска редактора вводите их заново
   в Publishing Settings, иначе релизная сборка остановится с ошибкой.

### Каждый релиз

1. Проверьте версию: **Player Settings → Other Settings**
   - `Version` (например `1.0.1`) — видна пользователю;
   - `Bundle Version Code` — целое число, должно **увеличиваться** с каждой загрузкой в стор.
   Сборщик версию не меняет.
2. Убедитесь, что в `MobileAdsConfig.asset` стоят ваши ID блоков и снята галка `Use Demo Ad Units`.
3. Введите пароли keystore, если редактор перезапускался.
4. Запустите сборку:
   - **RuStore** → Tools → Crossword → Android → **Build APK (release)**
   - **Google Play** → Tools → Crossword → Android → **Build AAB (release)**
5. Результат появится в `Builds/Android/` (папка не попадает в git).

Первая сборка идёт долго (IL2CPP компилирует код для двух архитектур, 30–40 минут),
последующие — минуты.

### Что нельзя менять после публикации

- **Package name** `com.tupuppo.crossword` — идентификатор приложения в сторах и в кабинете РСЯ.
- **Keystore** — приложение, подписанное другим ключом, стор не примет как обновление.

### Дополнительно для монетизации

Разместите файл `app-ads.txt` на сайте, указанном в кабинете разработчика стора, по инструкции РСЯ —
без него часть рекламодателей не выкупает показы.

## Настройки Android, которые применяет сборщик

| Настройка | Значение | Почему |
|---|---|---|
| Package name | `com.tupuppo.crossword` | Совпадает с приложением в кабинете РСЯ |
| Scripting backend | IL2CPP | Требование сторов |
| Target architectures | ARM64 + ARMv7 | Требование Google Play (ARM64) и старые устройства |
| Minimum API Level | 26 (Android 8.0) | Адаптивная иконка и требования SDK |
| Target API Level | Auto (самый свежий установленный) | РСЯ требует 31+ |
| Managed stripping | Low | Не вырезать коллбэки рекламы |
| Internet permission | Require | Реклама загружается по сети |
| Иконка | Adaptive: фон-градиент + арт на переднем слое | При minSdk 26 Unity поддерживает только адаптивную |
| Custom gradle templates | включены | В них EDM4U прописывает зависимости РСЯ |

### Как заменить иконку

Арт лежит в **`Assets/Art/Icon/icon_source.png`** (квадратный, 512×512 и больше). Чтобы поменять
иконку, положите новый файл под тем же именем, удалите `icon_background.png` и `icon_foreground.png`
рядом с ним и выполните **Tools → Crossword → Android → Apply Player Settings** — слои соберутся заново.

Лаунчер Android показывает центральные две трети иконки и обрезает её по маске (круг, скруглённый
квадрат), поэтому сборщик делает так: арт уменьшается до 78 % канвы и кладётся на передний слой со
скруглёнными углами, а фоновый слой заливается градиентом в цветах самого арта. Так композиция не
обрезается ни одной маской.

Название приложения под иконкой берётся из **Product Name** — сейчас «Мастер кроссвордов».
Оно же показывается в заголовке WebGL-страницы. Название в магазине задаётся отдельно в кабинете
разработчика. Важно: от Product Name зависит папка сохранений в WebGL-версии, поэтому при его смене
прогресс игроков, сыгравших под прежним названием, не подхватится. На Android сохранения привязаны
к package name и смены названия не замечают.

### Экран загрузки

Splash настраивается скриптом `Assets/Scripts/Editor/SplashScreenSetup.cs` и применяется при каждой
сборке: сначала стандартный логотип Unity, затем логотип студии из `Assets/Art/Splash/splash_logo.png`,
оба по 2 секунды, одинаковая анимация (Dolly), фон чёрный. Настройки splash общие для всех платформ,
поэтому логотип появляется и в версии для Яндекс Игр. Чтобы заменить логотип, положите новый файл по
тому же пути и выполните **Tools → Crossword → Apply Splash Screen**. Логотип Unity убрать нельзя на
лицензии Personal.

`Assets/link.xml` запрещает вырезать сборку `YandexMobileAds`: её коллбэки вызываются из Java по
имени метода, и стриппинг кода их не видит.

## Если что-то пошло не так

| Симптом | Причина и что делать |
|---|---|
| Приложение падает при старте, в Logcat `EntryPointNotFoundException: IsInitSDK_js` | В Android-дефайны вернулся `YandexGamesPlatform_yg`. Tools → Crossword → Fix Scripting Defines, дождаться перекомпиляции, собрать заново |
| Сборка прервалась с текстом «start the build again» | Дефайны были исправлены перед сборкой. Просто запустите сборку ещё раз |
| Gradle не находит библиотеки РСЯ | Tools → Crossword → Android → Resolve Dependencies (или Assets → External Dependency Manager → Android Resolver → Force Resolve) |
| Диалог «Enable Jetpack?» | Ответить **Yes**, иначе сборка не пойдёт. Настройка уже прописана в `ProjectSettings/GvhProjectSettings.xml` |
| Диалог «Missing Signature» при импорте пакетов | Пакеты OpenUPM не подписаны, это нормально — продолжить импорт |
| Предупреждения EDM4U «Could not find UnityEditor.Android.PostProcessAndroidPlayer», «Failed to determine the most recently installed Android SDK version» | Безвредны на Unity 6, сборке не мешают |
| Релизная сборка останавливается с ошибкой про демо-блоки | Не вписаны ID блоков РСЯ или не снята галка `Use Demo Ad Units` |
| Релизная сборка останавливается с ошибкой про keystore | Не выбран свой keystore или не введены пароли после перезапуска редактора |
| В редакторе реклама «показывается» мгновенно | Так и задумано: SDK РСЯ в редакторе — заглушка, показ имитируется за 1 секунду |
| Межстраничная не показывается | Сработали правила: первые 60 секунд после запуска, интервал 90 секунд, либо недавно был ролик за награду. В консоли видно причину: `[Ads] interstitial skipped: …` |
| Резолв падает с «JAVA_HOME is not set» | Gradle запускается отдельным процессом и не видит JDK. Переменная подставляется автоматически при запуске редактора; вручную — Tools → Crossword → Android → Set JAVA_HOME For Editor |
| Сообщения «More than one global light on layer» при сборке | Особенность URP 2D, к рекламе и сборке отношения не имеет |
